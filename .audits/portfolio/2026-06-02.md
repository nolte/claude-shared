## Findings

### Warning

- **[portfolio-management §Documentation rendering / Hard rule "no-invention"] `nolte/workstation` has a manifest but no `project/mission.md`.**
  The manifest is valid (1 capability, all fields present), but the repository
  ships no `project/mission.md`, so the rendered inventory
  (`docs/<lang>/portfolio/`) emits the missing-mission placeholder added in
  PR #258 rather than a quoted mission. Remediation: author
  `project/mission.md` in `nolte/workstation` via `mission-define`; the next
  Render then quotes a real mission and this finding clears.

- **[portfolio-management §Gap analysis (spec-demanded gap + copy-paste smell)] `nolte/gh-plumbing` provides an undeclared portfolio-wide capability.**
  `gh-plumbing` is named in the global tech-stack baseline
  (`portfolio/tech-stack.yml`: "nolte/gh-plumbing as the source of reusable
  CI/CD workflows … consumed by every nolte/* repository") and its reusable
  workflows are consumed by ≥3 members (blog, claude-shared, workstation — e.g.
  `automerge.yaml`, `release-*.yml` referencing `gh-plumbing`). At ≥3-recurrence
  this clears the §Gap analysis copy-paste-smell threshold, yet `gh-plumbing`
  ships **no `project/portfolio.yml`**, so the reusable-CI/CD capability is
  unattributed and undiscoverable in the inventory. Remediation: Bootstrap a
  manifest in `nolte/gh-plumbing` declaring the reusable-workflows capability
  (and `nolte/taskfiles` similarly, for the shared Taskfile collection).

- **[portfolio-management §Capability inventory per repository] 14 Portfolio-Members carry no `project/portfolio.yml`.**
  Every own (non-fork, non-archived, non-opted-out) repository is a
  Portfolio-Member and MUST either ship a manifest or declare
  `portfolio: excluded` in `CLAUDE.md`. Missing (14):
  `ansible-reachy-mini-bootstrap`, `claude-home-assistant`,
  `claude-reachy-mini`, `cookiecutter-gh-project`, `esphome-configs`,
  `gh-plumbing`, `k8s-home-lab`, `kamerplanter`, `kamerplanter-ha`,
  `reachy-mini-app`, `reachy-mini-mcp`, `taskfiles`,
  `terraform-github-bootstrap`, `vibe-coding`. Eleven of these already ship a
  `CLAUDE.md` (explicit project intent, higher priority);
  `gh-plumbing` and `taskfiles` are capability-bearing (see the finding above).
  Three lack a `CLAUDE.md` (`esphome-configs`, `k8s-home-lab`, `vibe-coding`)
  and may be the cheapest opt-out candidates. Remediation: per repository, run
  `portfolio-audit` Bootstrap to author a manifest, or add the
  `portfolio: excluded` marker with a one-line rationale.
