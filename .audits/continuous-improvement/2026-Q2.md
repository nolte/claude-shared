- **Notes**: The `security_relevance` matrix axis currently treats a PR label literally named `security` as a security signal. In the 2026-06-07 audit this produced a **false `Critical`** for `nolte/kamerplanter` PR #140, whose `security` label is Renovate's **group label** for a version-**pinning** group (`renovate.json5`: `groupName: 'security pinned versions'`, `matchFileNames: ['.github/renovate-pins.yaml']`, "read by security workflows") — not a `vulnerabilityAlerts`/CVE advisory. Update both the spec rule and the `matrix-axes-and-report.md` restatement so they can't drift.
