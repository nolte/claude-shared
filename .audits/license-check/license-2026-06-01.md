## Conveyed vs. arm's-length

The distributed plugin artifact (the marketplace) is Markdown (skills, specs,
agents), JSON manifests, and the bundled `image-generate` Python script — all
own code under MIT. **No third-party dependency is shipped.** `mkdocs*`,
`pytest`, `yamllint`, the pre-commit tools, and the Vale style packages run
arm's-length (docs build, dev, CI) and never reach a consumer. This determines
that every copyleft finding below sits in the `review` tier, not `deny`.

## Review-tier findings (all acceptable, all arm's-length)

- **yamllint (GPL-3.0-or-later).** Strong copyleft. Run as a pre-commit hook in a
  separate process; never linked or shipped. The GPL source-disclosure
  obligation triggers on conveying, not on running the tool, so no obligation
  falls on this repository. Accepted as a documented review exception. A
  permissive alternative for plain YAML validity (`check-yaml` from
  pre-commit-hooks) exists but does not replace style linting.
- **certifi, pathspec (MPL-2.0).** Weak, file-level copyleft. Transitive,
  arm's-length, not conveyed. No obligation on this repository's files.

No `deny`-tier findings: no conveyed or networked component carries strong or
network copyleft.
