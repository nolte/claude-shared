# Datenschutzhinweis

Stand: 1. Juni 2026

Diese Seite ist die Dokumentation des nicht-kommerziellen Open-Source-Projekts
`claude-shared`. Sie verarbeitet selbst keine personenbezogenen Daten einer
Nutzerschaft—es gibt keine Datenbank, keine Anmeldung, keine Analyse- oder
Tracking-Funktion. Der folgende Hinweis betrifft ausschließlich die technisch
unvermeidbare Verarbeitung durch den Hosting-Anbieter.

## Verantwortlicher

Verantwortlich im Sinne der DSGVO ist die Maintainer-Rolle des Projekts
`claude-shared`. Kontakt ausschließlich über die öffentliche Issue-Verwaltung
des Projekts:

- <https://github.com/nolte/claude-shared/issues>

Es werden bewusst keine persönlichen Kontaktdaten veröffentlicht; das Angebot
wird privat und ohne kommerziellen Zweck bereitgestellt.

## Hosting über GitHub Pages

Diese Dokumentation wird über **GitHub Pages** ausgeliefert, betrieben von der
GitHub, Inc. (USA) bzw. der GitHub B.V. (Niederlande). Beim Aufruf der Seite
verarbeitet GitHub technisch notwendige Verbindungsdaten—insbesondere die
**IP-Adresse** des aufrufenden Geräts—in Server-Logs, um die Auslieferung zu
ermöglichen und Missbrauch abzuwehren. Auf diese Logs haben die Projekt-Maintainer
keinen Zugriff.

- **Rechtsgrundlage:** berechtigtes Interesse an der sicheren, funktionsfähigen
  Bereitstellung der Dokumentation (Art. 6 Abs. 1 lit. f DSGVO).
- **Drittlandübermittlung:** Da GitHub in den USA ansässig ist, findet eine
  Übermittlung in ein Drittland statt. GitHub stützt diese auf
  Standardvertragsklauseln bzw. das EU-US Data Privacy Framework.
- Einzelheiten zur Datenverarbeitung durch GitHub:
  <https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement>

## Keine Cookies, kein Tracking

Die Seite setzt **keine** Analyse- oder Tracking-Cookies, bindet **keine**
Drittanbieter-Tracker, Tag-Manager oder Fingerprinting-Skripte ein. Verwendet
wird ausschließlich technisch notwendige lokale Speicherung im Browser
(z. B. die gewählte Hell-/Dunkel-Darstellung und der clientseitige Suchindex).
Diese Speicherung ist für den Betrieb unbedingt erforderlich und damit nach
§ 25 Abs. 2 TDDDG **einwilligungsfrei**—ein Cookie-Banner ist nicht erforderlich.

## Ihre Rechte

Soweit personenbezogene Daten verarbeitet werden, stehen Ihnen die Rechte auf
Auskunft (Art. 15), Berichtigung (Art. 16), Löschung (Art. 17), Einschränkung
(Art. 18), Datenübertragbarkeit (Art. 20) und Widerspruch (Art. 21) zu.
Anliegen richten Sie bitte über die oben genannte Issue-Verwaltung an die
Maintainer. Unabhängig davon besteht ein Beschwerderecht bei einer
Datenschutz-Aufsichtsbehörde (Art. 77 DSGVO).
