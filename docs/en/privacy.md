# Privacy Notice

Last updated: June 1, 2026

This site is the documentation of the non-commercial open-source project
`claude-shared`. It processes no personal data of any user population
itself—there is no database, no sign-in, and no analytics or tracking. The notice below
concerns only the technically unavoidable processing performed by the hosting
provider.

## Controller

The controller within the meaning of the General Data Protection Regulation
(GDPR) is the maintainer role of the
`claude-shared` project. Contact is exclusively through the project's public
issue tracker:

- <https://github.com/nolte/claude-shared/issues>

No personal contact details are published by design; the site is provided
privately and for non-commercial purposes.

## Hosting via GitHub Pages

This documentation is served via **GitHub Pages**, operated by GitHub, Inc. (USA)
and GitHub B.V. (Netherlands). When you access the site, GitHub processes
technically necessary connection data—in particular the **IP address** of the
requesting device—in server logs to deliver the content and to prevent abuse.
The project maintainers have no access to these logs.

- **Legal basis:** legitimate interest in the secure, functional provision of the
  documentation (Art. 6(1)(f) GDPR).
- **Third-country transfer:** because GitHub is based in the USA, a transfer to a
  third country takes place. GitHub relies on Standard Contractual Clauses and the
  EU-US Data Privacy Framework for this.
- Details on GitHub's processing:
  <https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement>

## No cookies, no tracking

The site sets **no** analytics or tracking cookies and embeds **no** third-party
trackers, tag managers, or fingerprinting scripts. It uses only technically
necessary local storage in your browser (for example the chosen light/dark theme
and the client-side search index). This storage is strictly necessary for
operation and therefore exempt from consent under § 25(2) TDDDG (German Act on
Data Protection in Telecommunications and Digital Services /
Telekommunikation-Digitale-Dienste-Datenschutz-Gesetz)—no cookie banner
is required.

## Your rights

Where personal data is processed, you have the rights to access (Art. 15),
rectification (Art. 16), erasure (Art. 17), restriction (Art. 18), data
portability (Art. 20), and objection (Art. 21). Please direct any request to the
maintainers via the issue tracker named above. You also have the right to lodge a
complaint with a data protection supervisory authority (Art. 77 GDPR).

## External links

The documentation links to external sites (in particular `github.com`). Their
content and data processing are the sole responsibility of the respective
providers; their privacy policies apply.
