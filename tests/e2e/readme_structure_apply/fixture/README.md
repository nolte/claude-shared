# Widget Toolkit

A small toolkit for rendering declarative widgets.

## Purpose

Widget Toolkit renders widgets from a declarative configuration so product teams ship
dashboards without hand-writing layout code.

## Usage

Install and render:

    pip install widget-toolkit
    widget render config.yaml

## Structure

- `src/` — the renderer
- `tests/` — the test suite

## Related repositories

- widget-themes — shared theme presets

## Status

Beta. The configuration schema is stable; the CLI surface may still change.
