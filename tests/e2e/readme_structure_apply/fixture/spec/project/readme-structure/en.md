# README Structure

Status: draft

## Requirements

- A README MUST start with an H1 title followed by a one-line tagline.
- A README MUST contain these six sections, in this order: Purpose, Usage, Structure,
  Related repositories, Status, License.
- The README MUST stay within a 200-line budget.

## Acceptance Criteria

- [ ] The README has an H1 and a one-line tagline.
- [ ] All six required sections are present and in the required order.
- [ ] A "License" section is present.
