# Example 02 — Render is idempotent when no manifests changed

A Render run from inside `claude-shared` refreshes the committed
snapshot `portfolio/aggregate.yml` and regenerates the aggregated
portfolio inventory under `docs/<lang>/portfolio/` via the generator
`scripts/docs/gen_portfolio.py` (`task docs:portfolio`). Because no
Portfolio-Member's `project/portfolio.yml` or `project/mission.md`
has changed since the previous render, the freshly assembled snapshot
and the regenerated pages are byte-identical to what is already on
disk, `mkdocs build --strict` passes, and `git diff --exit-code`
reports no drift. Exercises Operation 2's no-change happy path and the
two-stage snapshot-then-generator mechanism.

## Input prompt

> Render the portfolio inventory.

## Input files

The active checkout is `claude-shared`; both detection markers
(`.claude-plugin/plugin.json` and
`spec/portfolio/portfolio-management/`) are present.

`portfolio/aggregate.yml` already exists from the previous render, as
do the generated `docs/en/portfolio/index.md` and
`docs/de/portfolio/index.md` (each carrying the generator's
`<!-- AUTO-GENERATED by scripts/docs/gen_portfolio.py ... -->` header).

The resolved Portfolio-Member set is the four repositories that ship a
`project/portfolio.yml`: `nolte/blog`, `nolte/claude-shared`,
`nolte/vale-style`, and `nolte/workstation`. All but `nolte/workstation`
also ship a `project/mission.md`. None of those files have been
modified since the previous render — every relevant file's last commit
on its default branch is older than the previous Render run's commit on
`claude-shared`.

`spec/.spec-config.yml` declares `languages: [en, de]`.

No prior Audit operation ran in this turn.

## Expected behaviour

1. **Repository-role detection passes.** The skill confirms it is
   inside `claude-shared` and selects the Render operation.
2. **Manifest collection runs afresh.** Because the same conversation
   has not already collected manifests in this turn (no preceding
   Audit), the skill performs the same `gh api` collection flow as
   Operation 1 step 2, and additionally fetches each member's
   `project/mission.md`. Missions are quoted **verbatim**; for
   `nolte/workstation`, which has no `project/mission.md`, the skill
   records an empty `mission_statement` and notes the gap as a
   `Warning` for the next Audit (it never invents a mission).
3. **Snapshot assembled** into `portfolio/aggregate.yml`
   (`schema_version: 1`, a `members:` list, an empty `historical:`
   list). Each member carries `repo`, `repo_url`, the verbatim (or
   empty) `mission_statement`, and its `capabilities:` (`name`,
   `description`, `status`, `audience`, `since`). The member-level
   `peers:` list is derived from each manifest's per-capability
   `<repo>:<capability>` references — `nolte/blog` resolves to
   `peers: [nolte/claude-shared]`; the other three resolve to
   `peers: []`. Because nothing changed, the assembled snapshot is
   byte-identical to the committed `portfolio/aggregate.yml`.
4. **Generator run** via `task docs:portfolio` (equivalently
   `python3 scripts/docs/gen_portfolio.py`). It rewrites
   `docs/en/portfolio/index.md` and `docs/de/portfolio/index.md` as a
   pure function of the snapshot: one section per member, capability
   tables with status badges, the `flowchart LR` Mermaid capability
   map carrying the mandatory `<!-- diagram-source: ... -->` marker
   (English-only labels even inside `docs/de/`), the repo-to-repo peer
   edge `nolte/blog -.peer.-> nolte/claude-shared`, the
   missing-mission placeholder under `nolte/workstation`, and the
   "Historical capabilities" appendix rendered with its empty-state
   line (no archived repositories). The skill does **not** hand-write
   any `docs/<lang>/portfolio/*.md` page.
5. **Build verified.** The skill runs `task docs` (which invokes
   `mkdocs build --strict`); the build passes.
6. **Idempotency confirmed.** Because no manifest and no
   `project/mission.md` changed since the previous render, the freshly
   assembled snapshot and the regenerated pages are byte-identical to
   what was on disk: `git diff --exit-code portfolio/aggregate.yml
   docs/en/portfolio docs/de/portfolio` reports no drift — the same
   gate CI enforces. The closing message in the operator's language
   notes this: lists the snapshot plus the two regenerated paths, names
   the four Portfolio-Member sections, and adds the one-line note that
   the rendered output did not change.
7. **Hard rules honoured.** No source-of-truth manifest modified; no
   spec edited; nothing published (publication remains the `task docs`
   / MkDocs pipeline's job); nothing written outside `claude-shared`;
   no `docs/<lang>/portfolio/*.md` page hand-edited (only
   `portfolio/aggregate.yml` is authored — the generator owns the
   pages); and no mission or audience text invented (every quoted block
   is verbatim, and the missing `nolte/workstation` mission renders a
   placeholder rather than a fabricated statement).
